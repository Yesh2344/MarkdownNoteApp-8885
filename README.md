# MarkdownNoteApp 📓

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Bash](https://img.shields.io/badge/bash-5.0%2B-brightgreen.svg)](https://www.gnu.org/software/bash/)

A lightweight, **production‑ready** Bash application for creating, managing, and searching Markdown notes. 
It follows modern Bash best practices, includes structured logging, configuration handling, and a test suite.

## Features

- Create, list, view, delete, and search Markdown notes.
- Configurable notes directory via `.env`.
- Structured logging (`INFO`, `WARN`, `ERROR`) with timestamps.
- Robust error handling (`set -euo pipefail`).
- Simple, well‑documented Bash modules.
- test suite (`test_notes.sh`).
